# Publication scope

This public repository contains newly prepared technical documentation and aggregate result tables based on the author's supplied research materials.

## Included

- Research question, reported dataset selection and architecture.
- Baselines, reported runtime parameters and metric definitions.
- Aggregate answer results, evidence ablations and paired intervals.
- Primary reference links and clear reproduction limitations.

## Excluded

- Original experiment source code, tests and binary executables.
- Full or selected HotpotQA records, passage text, questions and gold answers.
- Per-question predictions or raw responses.
- Model weights, native libraries, environments and caches.
- Manuscript files, author forms, telephone numbers, email addresses and other personal contacts.
- API credentials, tokens, configuration secrets and private workplace materials.

The unavailable original project code has no confirmed distribution license in the reviewed materials and is not published. No broad open-source license is assigned to it. Upstream dataset, evaluator and model licenses apply independently to those assets.

Only the files listed in this repository's documentation/tables publication were prepared for upload; unrelated source documents and local working files are outside the publication. This scope does not assert that an unavailable original archive was completely screened.

Any future release of code, a journal or dataset derivatives requires an actual review of those recovered files and their permissions. Adding a link to an upstream asset does not redistribute that asset.
